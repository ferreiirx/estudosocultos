# **App Name**: Mind Portal Landing

## Core Features:

- Hero Section with Video Embed: Display a prominent hero section with a video embed from Wistia, designed to capture user attention immediately.
- Symbol Carousel: Implement a carousel showcasing mystical symbols and images, enhancing user engagement.
- FAQ Section: A collapsible FAQ section that leverages generative AI tool that uses its reasoning ability to respond to support queries.
- Responsive Layout: Ensure the landing page is fully responsive across various devices (desktop, tablet, mobile) for optimal viewing and interaction.
- Call-to-Action Buttons: Strategically placed 'Call-to-Action' (CTA) buttons with a neon hover effect to drive conversions.
- Social Proof Section: Display social proof with customer testimonials to build trust and credibility.

## Style Guidelines:

- Primary color: Deep purple (#6226FF) to convey mysticism and elegance.
- Background color: Dark gray-blue (#222B45) with a blue-to-purple gradient for a mysterious ambiance.
- Accent color: Gold (#FFD700) for buttons and highlights to add a touch of sophistication.
- Headline font: 'Playfair', a modern serif font for headlines, conveying elegance.
- Body font: 'PT Sans', a sans-serif font for body text, for readability.
- Mobile-first design approach for optimal user experience on smaller screens.
- Smooth autoplay carousels to display testimonials, symbols and benefits.
